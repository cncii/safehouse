## 0. 项目关键事实（判定一律以本段逐字为准，不得改值）

- **开发形态**：单人开发，约 15–20 h/周；纯本地、无联网、无账号、无云存档、无行为追踪、无内购。
- **四条状态硬规则**：HP=0 即死；体力降至 **5%** 触发强制睡（边沿触发，非电平）；饥饿=0 时 **-1.0%HP/s**；渴=0 时 **-1.5%HP/s**；野睡（非床上）结束 **-15 HP**。
- **时间**：名义 GH 永不换算现实秒；`clock GH = 72 s`；一局纯玩法无死亡通关 **4.5–5.5 h**（含死亡重开/加载的墙钟口径为 5.5–6.2 h）。全季 = **816 480 帧**，1 GH = **4 320 帧**，失能 = **216 帧 = 3.60 s**，起手 = **8 帧**。
- **存档**：每日 **05:00** 单槽自动存档 + 退出时手动存档，**写入同一文件**（无多槽）；死亡重开从次日 **06:00** 清晨；`day_seed = mix64(global_seed ^ (day × GOLDEN))`，同日重开世界快照须 5/5 全等；05:00 后 `day_seed` 锁定，重试只能练技术不能刷随机。
- **事件系统**：影响面封闭为 **4 类**：`num` / `flag` / `time` / `spawn`，禁止通用脚本引擎。
- **阶段划分**：**阶段 A（day 1–7）** 可跳夜，18:00 后物化、20:00 后遇敌升级、20:00 门锁（19:59 可出 / 20:00 拒）；**阶段 B（day 8–14）** 7 夜无跳夜、全阶段常锁、夜 7（D14）晨清场达成通关。
- **循环系统**：食物 L1/L2/L3 = 0.12 / 0.19 / 0.22 单位·GH⁻¹；净水 = 0.15 / 0.20 / 0.24 单位·GH⁻¹；零件仓容 20、阶段 B 零件需求 48；三段效率 100% / 溢出 50% / 软上限 0%。
- **科技树**：总节点 **24**（分母禁砍），单局解锁 **[12, 16]** 中位 14。
- **挂机兜底**：连续 3 tick 无有效输入 → 60 s 后自动暂停；夜间挂机兜底 ≤ 8 min（480 s）硬上限，结算恒 **12 GH（51 840 帧）**。
