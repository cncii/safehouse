## 二、★ 变异测试又抓出 3 个真判据缺陷

### 缺陷 1（严重）：1012(2)「降级有日志记录」是**假绿**

**现象**：C13（把降级日志换成 `pass`）跑完，判据**照样绿**。

**根因**：判据扫**所有**日志文件。Godot 每次启动会把旧 `godot.log` 改名归档
（`godot<时间戳>.log`），**历史归档里残留着上一次的 `null_backend` 记录** →
扫到它就判绿 → 变异完全测不出来。

**修法**：**只读活动日志 `godot.log`**（Godot 启动时归档旧的、新建空的，
所以它只含**本次运行**的内容）。历史归档一律不读。

> 教训：判据"在日志里找某个东西"时，**必须限定到本次运行的时间窗**，
> 否则历史残留 = 恒绿。这类假绿比假红危险——判据看起来有牙，其实没测。

### 缺陷 2：C10 变异体**不可达**（不是判据问题，是变异选错位置）

原 C10 打在 `if _backend == null: _degrade("init_failed")` 那一行。
但**加了 GodotSteam 之后那条分支根本不执行**（走的是 `_degrade("binding_script_missing")`）
→ 变异体落在死代码上 → 判据测不到它。

**修法**：改打 `_degrade()` **函数体**（两条路径的共同点），
并让 `_degrade` **整个函数什么都不做**（`return`）——不是空变异（只加注释不改行为那种）。

> 教训：★ **变异体本身也会写错**。改 `if` 为 `if false` 想模拟"守护失效"，
> 但 `else` 分支仍在跑 → 判据全绿。**先验证"变异体确实制造了缺陷"**，
> 否则会把好判据改坏。

### 缺陷 3：工具把"探针 0 条断言"误判成"捕获"（**假绿**）

C19 的锚点我写成 `...\n\t\treturn   # P9 幂等：同键不重复发放`（漏了中文后半段），
`replace` 把中文注释的 `/` 留在 `if false:` 后面 →
`Expected statement, found "/" instead.` → **整个文件编译失败** → 探针 0 条断言
→ 工具按"断言数变少 = 崩溃式捕获"判成"捕获"。

**这是最危险的一类假绿**：判据看起来抓到了变异，其实探针根本没跑。

**修法**：
1. 工具：**0 条断言 = 探针未跑起来（编译/加载失败）→ 判「变异无效」，不算捕获**。
2. 锚点纪律：跨行片段必须**完整匹配到行尾**（含中文注释）。

## 三、★★ 变异锚点纪律（三次踩坑的汇总，通用）

| # | 纪律 | 踩坑实录 |
|---|---|---|
| 1 | **锚点必须命中所有相关路径的共同点** | C10 打在 `init_failed` 分支 → 有 GodotSteam 后是死代码 → 变异不可达 |
| 2 | **锚点不能与另一个变异体重复** | C10 与 C14 都打 `_backend = load(NULL_PATH).new()` → 同一行两个变异体，测同一件事，覆盖数虚高 |
| 3 | **跨行片段必须完整匹配到行尾** | C19 漏了中文注释后半段 → 编译失败 → 探针 0 条断言 → 工具误判成"捕获" |
| 4 | **注意文件行尾（CRLF vs LF）** | `steam_service.gd` 是 CRLF → `\n` 跨行锚点 hits=0；`event_system.gd` 是 LF |
| 5 | **不能是空变异** | C10 改过一次只加注释不改行为 → 判据当然测不出来 |
| 6 | **编译期错误型变异不行** | 整个文件加载失败 → 目标判据根本执行不到（同 C15 那次） |

**校验脚本（跑变异前必做）**：锚点命中次数必须**恰好 1**；
target / chain_ok 里的每个名字都必须能在探针源码的 `_t("...")` 里找到；
并检查**不同变异体之间没有重复锚点**。

## 四、★ 判据设计的一个通用教训（来自 P17b 探针自身）

写 P17b 探针时我犯了一个**自己才抓得到**的错：判据里用了
`_ev.fire(ev_id, {"day": 1, "slot": 0})`，而 `fire()` 读的 ctx 键是 **`slot_index`**。
键名写错 → 查重键对不上 → 走了发放路径 → 判据红。

**但这不是产品缺陷，是我的判据写错了。** 修法：**从已记录的日志里取真实的键**
（`event_log[0].key` 拆成 `id:day:slot`），再用它重放——
这样判据自动与实现对齐，且不会因为键名约定变化而失效。

> 推论：**判据应该从"被测系统实际产生的数据"取输入，而不是自己拼输入**。
> 自己拼输入 = 把实现约定硬编码进判据 = 约定变了判据就假红。
