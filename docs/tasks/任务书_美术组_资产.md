# 任务书 · 美术组（资产管线 + 风格契约）

**编号**：TASK-ART v1.0（2026-10-19）｜**上游**：架构方案 R6（素材拼贴感）+ §7（性能预算）｜**验收人**：老板 + `tools/check_assets.py`

## 1. 一句话目标

建立一条"素材包筛选 → 风格统一 → 图集规范"的管线，让买来的素材变成**能直接接进工程**的资产——本项目美术的最大风险不是画得不好，是**三个来源的素材摆在一起出戏**。

## 2. 范围

| 做 | 不做 |
|---|---|
| `docs/style_contract.md` 素材准入单（先写它，再买素材） | ❌ 从零全套手绘（素材包为主是既定方向） |
| `assets/shaders/palette_map.gdshader` 色板统一 shader | ❌ 骨骼动画（项目定稿：无骨骼，像素帧动画） |
| 素材筛选/采购清单（itch.io / 商店）+ 授权记录 | ❌ UI 代码（界面布局归表现组，你们只出 UI 件素材） |
| 图集整理 + 命名规范 + 立绘规格 | ❌ 9 类地点全量场景（按批次走，见 §5） |

## 3. 名下文件（可改）

```
assets/**（sprites/portraits/tilesets/fonts/shaders）
docs/style_contract.md
tools/check_assets.py 不可改——它是你的验收器，改它=作弊
```

**禁改**：`src/**`、`data/**`、`project.godot`。

## 4. 风格契约（已定稿，写进 style_contract.md 的内容，逐条是拒收理由）

| # | 条款 | 违反后果 |
|---|---|---|
| S1 | **16px 网格**，图块 16×16；角色帧 16 的倍数（如 16×24 / 16×32） | 混入 24px 素材 = 拒收，买了也不用 |
| S2 | 单素材 **≤32 色**；全项目统一 target palette（交 palette_map 后自动映射） | 超色先过 shader，再不行拒收 |
| S3 | **左上光源**；**顶视 3/4 角度**（RPG 式俯视） | 光源方向相反的素材并排 = 最明显的出戏 |
| S4 | **1px 深色描边**（有无描边不混用） | 同上 |
| S5 | 立绘单独规则：统一画布尺寸、统一半身裁切线、统一背景处理 | 立绘一帧一个样 = 事件 CG 全废 |
| S6 | 中文像素字体必须**含 license 文件**（嵌入分发，缺授权 = 不能用） | 法务风险，一票否决 |

**关键交付（优先级最高）**：`palette_map.gdshader`——把不同来源精灵的色板映射到统一 target palette。**一个 shader 顶 40 小时重绘**，是低成本统一风格最有效的手段。验收方式：拿两张来源不同的精灵图，开/关 shader 各截一张对比图。

## 5. 交付批次（对齐路线图，**严禁提前铺量**）

| 批次 | 内容 | 触发条件 |
|---|---|---|
| **第一批（现在做）** | style_contract.md + palette_map.gdshader + 采购清单（含授权）+ 中文字体 | 立即 |
| **MVP 批** | 主角 4 方向行走帧 + 挥砍/翻滚帧、**1 种丧尸**、tileset ×2（安全屋 + 超市）、四条状态条 UI 件 | 灰盒过了手感闸门后 |
| **可玩批** | +3 类地点 tileset（加油站/百货/药店）、事件立绘 ×3–5、图标 | 逻辑组 7+7 流程跑通 |
| **上架批** | 补齐 9 类地点、多周目立绘、成就图标 | 上架档启动 |

> ⚠ 架构 R1 的头号死因是**内容量爆炸**。**MVP 阶段美术只对应 1 个安全屋 + 1 个地点 + 1 种丧尸**——多做就是烧钱买返工（灰盒手感闸门可能推翻走位/帧需求）。

## 6. 验收（红绿）

```powershell
python tools/check_assets.py
```

| 规则 | 判据 |
|---|---|
| A1 | 所有 PNG 宽高为 16 的倍数（16×16/16×24/16×32…）|
| A2 | 图集最长边 ≤2048 |
| A3 | 命名 = 域前缀 + 小写蛇形（`char_hero_walk_down.png` / `tile_market_a.png` / `portrait_hero_neutral.png`）|
| A4 | 单文件 ≤32 色（Pillow 可用时）|

**人工验收**（老板看，不可替代）：同屏"两个来源的精灵并排"截图——看得出区别 = 未过 palette_map；看不出 = 过关。

## 7. 协作纪律

- 采购素材**先过 style_contract 再下单**——"不合规的素材买了也不用"是写进架构的省钱条款。
- 每批交付附**来源与授权清单**（素材名/站点/许可证类型）——Steam 上架会查。
- 与表现组（包 D）的接口：你们交 `assets/**`，他们接入；命名即契约，改名要通知。
- 灰盒（色块）阶段你们的素材**不上工程**——避免给手感调参制造噪音；第一批的 shader 和契约现在就可以做。
