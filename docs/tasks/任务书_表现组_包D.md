## 1. 一句话目标

把"玩家看得见的一切"做出来——HUD 四条状态、三块保命 UI、警报、场景切换。**你们的三块 UI 是两条必败路径的唯一解法**（知识型必败 R13'、净水 0.5 天破防倒计时），不是锦上添花。

## 4. 三块硬 UI（P1.5 必审项，设计已定稿，少一块 = 不达标）

1. **建造/停机瞬间三行**（知识型必败 R13' 的唯一解法）：
   ```
   菌菇栽培架 Lv1
     产出 <产出>/天    需求 <需求>/天
     ⚠ 缺口 <缺口>/天 —— 库存 <N>，约 <M> 天后耗尽
   ```
   建成/升级/停机那一刻必须出现，不是等库存低了才报。
   （原文此处曾有 2.88 / 4.80 / 1.92 三个示例值，已按 §8 纪律 1 移除——**文档里出现的数会被当成权威抄进实现**。
   实际值一律运行时读 `data/**/*.json`，本任务书不提供任何数值。）
2. **链状态面板**：各条链显示 产出 / 库存 / 还能撑几天 / 卡在哪一环（S10-b：风险"已缓解"必须有 UI 支撑，否则降级"已接受"）。
   > 🔴 **阻塞 W2，开工前必须澄清**：本条原写"**5 条链**（食物/净水/样本/电力/零件）"，
   > 但 `src/systems/loop_system.gd:30` 的链存储是 **4 条且集合不同**：`{ WATER, FOOD, POWER, MEDS }`——
   > 有**药品**、**无样本/零件**。同一个接口 `maintenance_urgency()` 两侧理解不一致 → 面板必然缺格或多格。
   > **待澄清**：① 链到底是 4 条还是 5 条？② 样本/零件是"链"还是只是背包资源（TASK-B 的 P12 里零件是背包基线 15–25）？
   > ③ 权威清单写在哪份 `data/**`？**此项不澄清，W2 不许开工**（改了就是返工：面板按 5 条做、接口返回 4 条）。
   >
   > ✅ **裁定（2026-10-20 17:35 · 表现组开工依据）**：逻辑组已在 `loop_system.gd` 用代码回答①——
   > `maintenance_urgency()` 返回 4 条 `{FOOD,WATER,MEDS,POWER}`，注释明确"链状态面板**四项**"（§9 校对记录 #1 亦确认接口已定）；
   > ③ `data/**` 无链清单 JSON → **接口即权威**。②样本/零件不是链。实现取**动态遍历接口返回值渲染**：
   > 接口给几条显示几条，"面板 5 条/接口 4 条"的返工模式被结构性消除。wiring 缺位（LoopSystem 实例无人挂 /root，core 欠件）时降级显示。
3. **库存两级预警**：任一资源 <2 天存量 黄→红 + 一次性音效（容错天数不在此处给数，运行时读 `data/balance/survival.json`；无预警 = 容错归零）。

## 5. 禁改清单

1. **UI 只读 + 上行 Command**：订阅 `StateStore.subscribe()`，禁止 `State.apply()`——单向数据流边界。
2. **零中文字面量**：一切玩家可见文本走 `Localize.text("KEY")`，键写进 strings.csv；check_i18n.py 扫到即 CI 拒绝。
3. **内部分辨率 640×360 整数缩放**（project.godot 已锁，门禁项）：不许出现小数缩放参数。
4. **audio 纯消费者**：只订阅状态播警报（饥饿/渴 <25% 持续可听、体力 ≤10% 心跳音），不回写任何东西。
5. 科技树锁定原因必须**具体到缺哪个节点**（`missing` 列表），只显示"未解锁"三个字 = 未达标。
   （⚠ 上游《模块分包说明》§2 包 D 未列此条，且**无判据编号** → 无法进 `tools/test.ps1` 断言。
   暂按**人工审查项**处理：需要老板补一个编号，或明确它只做人工验收、不进红绿。）
